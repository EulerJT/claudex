# Tool Use

Use for defining API tools, handling `tool_use` / `tool_result` content blocks, and
preserving pairing order.

Check tool schema, tool-use ID, result role, and adjacency. Do not confuse Claude Code
built-in tool names or permission rules with the Anthropic API tool contract.

Official entry point: https://docs.anthropic.com/en/docs/agents-and-tools/tool-use/overview
